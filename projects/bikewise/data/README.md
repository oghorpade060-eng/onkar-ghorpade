# Dataset attribution

**Fanaee-T, H. (2013). Bike Sharing [Dataset]. UCI Machine Learning Repository.**  
DOI: https://doi.org/10.24432/C5W894  
Dataset page: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset  
License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Run `python download_data.py` to retrieve the original archive from UCI. The downloader saves `hour.csv` and the original `Readme.txt`. Both downloaded files are excluded from Git. No paid account or API key is required.

The hourly CSV used here has 17,379 observations and covers Capital Bikeshare in 2011–2012. Its bytes are left unchanged. The project creates derived model parameters, aggregate charts and prediction metrics from that CSV.

Expected `hour.csv` SHA-256:

```text
e03de4ee4ef4dc376ac6e04bf829673c6269e8eba5c60fa121640fa2f829504f
```

For variable definitions and original research credit, read the downloaded `Readme.txt`. The source-code MIT license does not apply to the UCI dataset.
