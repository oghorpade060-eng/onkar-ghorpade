# Dataset provenance

Run `python download_data.py` to retrieve the UCI SMS Spam Collection.

- Creators: Tiago Almeida and José María Gómez Hidalgo; citation listed by UCI as Almeida, T. & Hidalgo, J. (2011).
- Source: https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection
- DOI: https://doi.org/10.24432/C5CC84
- License: Creative Commons Attribution 4.0 (CC BY 4.0).
- Exact `SMSSpamCollection` SHA-256: `7d039a24a6083ed9ef0f806ebad56bbb976e3aeb8de05669173bfdc4996c239d`.

Only the intended member is read from the ZIP; no arbitrary archive paths are extracted. The raw corpus is ignored by git. Keep real personal messages out of commits and example screenshots.
